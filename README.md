# Coder's Shop

A community marketplace for buying and selling digital gadgets, phones, laptops, and electronics.

## About

Coder's Shop connects local buyers and sellers who want to trade digital gadgets safely and easily. Users can browse listings, post items for sale, and discover great deals on pre-loved electronics.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- [Next.js](https://nextjs.org) App Router
- React + TypeScript
- Tailwind CSS
- shadcn/ui components

## Learn More

- [Next.js Documentation](https://nextjs.org/docs)
- [Tailwind CSS Documentation](https://tailwindcss.com/docs)

## Deploy

The app can be deployed to any platform that supports Next.js, such as [Vercel](https://vercel.com).
